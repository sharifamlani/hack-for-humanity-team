# docs/

Planning and reference material for the hackathon entry. Written before the build window —
documentation and research are allowed pre-event; application code is not.

| File | What it is | Read it when |
|---|---|---|
| `hackathon-brief.md` | Verified rules, schedule, tracks, judging, license requirement. **Source of truth.** | Any question about what the event requires |
| `idea-shortlist.md` | Candidate ideas per track + data sources to verify. | Friday night prep; 10:20 AM idea lock |
| `demo-script.md` | The 2-minute demo, written before the code. **This is the spec.** | Phase 1, before writing anything |
| `data-sources-verified.md` | 13 Miami civic data sources probed with real requests; what is live, what needs a key, what is a privacy hazard | Choosing a track; before building on any dataset |
| `pre-event-checklist.md` | Prioritized P0–P3 prep that is legal under "all code written during the event" | The night before / morning of |
| `idea-gotv-miami.md` | **Evaluation of the GOTV + voter ideal-point idea** — verified data paths, the congress.gov correction, scope cut, ethics constraints | Before building anything on this idea |
| `gemma4-integration.md` | **Gemma 4 verified** — model IDs, the closed-weight-default trap, the `thought` part trap, token budgeting | Before writing any model call, and before the demo |
| `parallel-build-playbook.md` | **How one builder uses agents to move fast** — the installed-vs-needed version matrix, the periphery/spine doctrine, what was configured, the dispatch template | Before dispatching any agent; and tonight, for the `claude update` item |
| `images/` | Pictures shown in the README. `team-grand-champion.jpg` is the team photo from the event | Adding or replacing a README image |
