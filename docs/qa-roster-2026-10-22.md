# Roster QA vs. official DOE listing - 2026-10-22

Roster checked: `data/candidates.csv` (95 rows; `data/candidates.json` has identical ids, names, districts, parties, `on_general_ballot`).

Official sources, fetched 2026-10-22:
- Federal + all offices: https://dos.elections.myflorida.com/candidates/CanList.asp?elecid=20261103-GEN (HTTP 200, 587 KB, real rows)
- Cabinet: ...&OfficeGroup=CAB (200, 43 KB)
- Legislature: ...&OfficeGroup=LEG (200, 240 KB)
- District geography: Census TIGERweb 2026 SLD Upper/Lower + 120th Congress layers (https://tigerweb.geo.census.gov/arcgis/rest/services/TIGERweb/Legislative/MapServer layers 0, 1, 2) and Census Geocoder (what the app itself calls).

"On the general ballot" rule used: DOE Status = Qualified, Primary not Eliminated, General column not "Unopposed". Write-in (WRI) candidates excluded. DOE rows with Status/Primary/General all "Unopposed" were elected at qualifying and are not on the ballot.

## Trap: DOE blocks plain curl
A plain `curl` gets HTTP 403 with a Cloudflare "Just a moment..." page (5.5 KB). With a browser User-Agent it returns the real page. Anything in the app that scrapes this site without a browser UA will silently get the challenge page.

## Mismatches ranked by visibility

1. State House 117, 118, 119 missing (6 candidates). Any voter in these three Miami-Dade districts sees no State House race at all. Highest-impact defect. Fix: add 6 rows (Chambliss D inc, Granda R; Castillo D, Redondo R inc; Sordo D, Porras R inc).
2. Unopposed districts (HD 104, 107, 109, 110, 111, 112, 114, 120) show no State House race with no explanation. A voter or judge may read this as a bug. Suggested: a line like "Unopposed - elected without a ballot contest".
3. State House 101 missing (Cassel R, Delmay D). Only a sliver of Miami-Dade; affects almost no one, but add if adding 117-119.
4. Venue (FL-24, SD-36, HD-108): no mismatches.

- Judicial, county, school board, municipal rows were out of scope.

## Reproduce
```
UA="Mozilla/5.0 (Windows NT 10.0; Win64; x64) AppleWebKit/537.36 Chrome/124 Safari/537.36"
B="https://dos.elections.myflorida.com/candidates/CanList.asp?elecid=20261103-GEN"
curl -sS -A "$UA" -o fed.html "$B"                    # federal + all offices (no UA -> 403)
curl -sS -A "$UA" -o CAB.html "$B&OfficeGroup=CAB"
curl -sS -A "$UA" -o LEG.html "$B&OfficeGroup=LEG"
curl -sS -G "https://geocoding.geo.census.gov/geocoder/geographies/address" \
  --data-urlencode "street=2750 NW 3rd Ave" --data-urlencode "city=Miami" --data-urlencode "state=FL" \
  --data-urlencode "zip=33127" --data-urlencode "benchmark=Public_AR_Current" \
  --data-urlencode "vintage=Current_Current" --data-urlencode "layers=all" --data-urlencode "format=json"
```
Parsing: each office is a table headed by `<b>Office</b>`; rows have District, Candidate "(PTY)", Status, Primary, General columns; blank district cell means same district as the row above.
